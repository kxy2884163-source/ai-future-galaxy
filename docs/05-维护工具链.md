# 05 · 维护工具链

> **适用**：网页开发项目（单人 / 小团队 / AI 辅助开发）
> **最后更新**：2026-07-29

---

## 🎯 核心理念

**AI 军师（规划/派活）+ AI 程序员（写代码/跑批）+ 人类（拍板/验收）**

军师不动手写代码，程序员不动脑拍方向。

---

## ✅ 工具选择

### 角色分工

| 角色 | 工具 | 职责边界 |
|---|---|---|
| **AI 军师** | OpenClaw（MiniMax-M3）| 规划 / 拆需求 / 派活 / 验收 / 复盘 · **不动手写代码** |
| **AI 程序员** | Codex CLI（npm 全局）| 写代码 / 跑批 / 改 workflow / 自测 · **不动脑拍方向** |
| **人类（老大）** | — | 拍板 / 验收 / 决策"值不值得做" |
| **版本控制** | Git + GitHub CLI | 代码历史 / 协作 / Code Review |
| **Skill 管理** | UI/UX Pro Max + 项目级 .agents/skills/ | 设计大脑 + 按需 skill |

### OpenClaw（军师）

| 维度 | 配置 |
|---|---|
| **模型** | MiniMax-M3（主力）+ MiniMax-M2.7（备用）|
| **入口** | 飞书群聊（group chat）|

## ❌ 不引入的工具（反模式）

| 工具 | 原因 |
|---|---|
| Docker Desktop | 前端项目不需要，supabase CLI 有内置 Docker |
| Kubernetes | 过度工程 |
| Terraform / Pulumi | 小项目 Vercel/Supabase 足够 |
| Datadog / New Relic | Sentry 够用，付费贵 |
| Jenkins / CircleCI | Vercel 内置 CI/CD 更好 |
| VS Code Server | Codex CLI 是主力，不需要 VS Code |
| npm（项目内）| 零构建原则，禁止本地 npm install |

## 🔧 日常操作命令速查

| 操作 | 命令 |
|---|---|
| **启动本地 server** | `node server.js`（port 8000）|
| **Codex 跑一个 prompt** | `codex "..."` |
| **Codex 查看日志** | `codex-cli logs` |
| **Git 提交** | `git add . && git commit -m "..." && git push` |
| **GitHub 查看 repo** | `gh repo view` |
| **Supabase 本地开发** | `supabase start` → Studio: `localhost:54323` |
| **Sentry 初始化** | `Sentry.init({ dsn: '...' })`（在 app.js 头部）|
