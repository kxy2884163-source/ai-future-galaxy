# 04 · 部署与运维

> **适用**：网页开发项目（MVP / 快速上线 / 零运维）
> **最后更新**：2026-07-29

---

## 🎯 核心理念

**三件套 + GitHub OAuth 统一账号 + git push 自动部署**

零手动部署——代码 push 到 GitHub → Vercel 自动 build + CDN 分发 → 上线完成。

---

## ✅ 技术选择

### 部署三件套

| 服务 | 作用 | 免费额度 | 触发付费条件 |
|---|---|---|---|
| **Vercel** | 前端 CDN 部署 + Serverless Functions | 100GB 流量 / 月 | 流量超限 |
| **Supabase** | Postgres + Auth + Storage + Edge Functions | 500MB DB / 1GB Storage / 50k MAU | DAU > 50k |
| **Sentry** | 错误监控（前端 SDK）| 5k 错误 / 月 | 错误量超限 |

### 统一登录（三件套共用 GitHub OAuth）

| 服务 | OAuth 方式 |
|---|---|
| **Vercel** | GitHub OAuth（关联 GitHub repo，一键部署）|
| **Supabase** | GitHub OAuth（用户登录 + developer settings 关联）|
| **Sentry** | GitHub OAuth（关联 GitHub repo，自动 SourceMaps）|

**好处**：一个 GitHub 账号贯穿全部，零多套凭据管理。

### CI/CD 流程

```
本地开发
  ↓ git commit
  ↓ git push
GitHub repo（main 分支）
  ↓ Webhook 触发
Vercel（自动拉取 / build / 部署到 CDN）
  ↓ 1-2 分钟
全球节点（CDN 生效）
```

### 自定义域名（可选）

| 步骤 | 操作 |
|---|---|
| **购买域名** | 阿里云 / 腾讯云 / Cloudflare |
| **DNS 解析** | CNAME 指向 `cname.vercel-dns.com` |
| **Vercel 绑定** | Project Settings → Domains → 添加域名 |
| **HTTPS** | Vercel 自动申请 Let's Encrypt 证书 |

---

## ❌ 不引入的技术（反模式）

| 技术 | 原因 |
|---|---|
| Nginx + 手动部署 | 需要登录服务器，CI/CD 更好 |
| Docker（前端项目）| 过度工程 |
| Jenkins / GitLab CI | 配置复杂，Vercel 内置 CI 够用 |
| PM2（长期进程）| 前端静态项目不需要 |
| 自建 Sentry | 运维成本高，官方 SaaS 够用 |
| Datadog / New Relic | 付费贵，Sentry 够用 |

---

## 🚨 Sentry 接入规范（必须做）

| 步骤 | 代码 |
|---|---|
| **安装 SDK** | `npm install @sentry/browser`（不需要，项目走 CDN）|
| **初始化** | 在 `app.js` 开头加 `Sentry.init({ dsn: '...' })` |
| **SourceMaps** | Vercel + Sentry 自动集成（关联 GitHub repo 后自动）|

---

## 📊 成本总结

| 阶段 | 月成本 |
|---|---|
| **MVP（< 50k MAU）** | $0 |
| **增长期（50k-500k MAU）** | ~$25-100 / 月（Vercel Pro + Supabase Pro）|
| **盈利后** | 按用量付费 |

**结论**：0 成本起步，盈利后再考虑付费升级。

---

## 🛡️ 安全基础

| 做法 | 说明 |
|---|---|
| **HTTPS** | Vercel 自动开启 |
| **环境变量** | `.env.local` 不提交 Git，Vercel dashboard 配置 |
| **API Key 保护** | Supabase ANON_KEY 只读，RLS 兜底 |
| **CORS** | Supabase 限制授权域名 |
| **依赖检查** | 定期 `npm audit`（如有本地依赖）|

## 📁 目录结构约定（部署相关）

```
project/
  ├── vercel.json        # Vercel 配置（可选，大多数情况不需要）
  ├── .env.local         # 本地环境变量（不提交 Git）
  ├── .env.production    # 生产环境变量（不提交 Git）
  └── .gitignore         # 忽略 .env / node_modules / .vercel
```
