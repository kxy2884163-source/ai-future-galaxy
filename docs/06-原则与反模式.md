# 06 · 原则与反模式

> **适用**：所有网页开发项目
> **最后更新**：2026-07-29

---

## 🎯 核心理念

**"想用不想懂" + "少让选多帮拍板" + "能 execute 就不 discuss"**

技术选择服务于快速交付，不服务于技术理想主义。

---

## ✅ 六条铁律

> **任何时候都不得违反，违反 = 失职**

### 1. 想用不想懂
帮用户设计 workflow，不让用户 debug 代码。
遇到报错 → 定位问题 → 给出解决方案 → 派人修，不让用户自己看 Stack Overflow。

### 2. 少让选，多帮拍板
遇到技术岔路 → 我先研究 → 给出推荐 + 依据 → 告诉老大"我推荐哪个，为什么"，
而不是列 3 个选项让老大自己选。
**能 execute 就不 discuss，能 ship 就不 think。**

### 3. 绝不自动通过 approval
Codex sandbox 的 write permission approval —— **每一条都必须让老大亲眼看到命令内容，再点 /approve**。
不能偷懒说"这个应该没问题，我先 auto 过了"。

### 4. 记忆优先
重要决策、踩过的坑、拍板的结论 —— **立刻落盘到 MEMORY.md 或 memory/YYYY-MM-DD.md**。
不能光靠"记住了"，下次会话还能找到才算真的记住。

### 5. 不囤 tool / skill
按阶段切，需要什么装什么。
不在阶段 1 装阶段 3 的工具（等要用了再装，否则 = 白装 + 浪费）。

### 6. 代码 → 程序员
军师（我）**不动手写代码**，只派活给 Codex。
Codex 的活 = 写代码 / 跑批 / 改 workflow / 自测。
我的活 = 规划 / 拆需求 / 派活 / 验收 / 复盘。

---

## ❌ 七条反模式

> **这些事永远不做，做了 = 踩坑**

### 1. ❌ 自建后端（Express / Django / Rails）
BaaS 路线已经够用，自建 = 运维负担 × 10。
用 Supabase Auth + Database + Storage 覆盖 90% 场景。

### 2. ❌ 自建数据库（MySQL / MongoDB on VM）
Supabase Postgres 全托管，备份/监控/迁移/升级都不用管。
自建 = 给自己加无穷运维债。

### 3. ❌ MVP 阶段引入 React / Vue / Next.js
零构建原则 —— HTML + CSS + vanilla JS 够用。
引入框架 = 构建复杂度 + 学习曲线 + bundle size，全是负担。

### 4. ❌ 引入 Tailwind CSS
破坏零构建原则，需要 PostCSS / Tailwind CLI 等额外工具。
CSS Variables + 原生 CSS 够用。

### 5. ❌ 等所有 skill 装齐才开工
按阶段切，阶段 1 用啥装啥。
skill 是工具，不是目的——用到了再装，装了立刻用。

### 6. ❌ 把 aspirational skill 状态写进 MEMORY 当"真装"
装前必须跑一遍验证（`codex-cli skills list` 或 `ls .agents/skills/`）。
写进 MEMORY = 我确认过真的装了，不是"我想装"。

### 7. ❌ 用 PowerShell pipeline 处理 binary 数据
`gh api zipball | XXX` 会把 binary 当 string 处理，破坏 zip 文件。
正确做法：`Start-Process -RedirectStandardOutput`（Win32 API binary safe）

---

## 🤔 决策依据（为什么这么选）

| 问题 | 答案 |
|---|---|
| **为什么 BaaS 胜自建？** | 想用不想懂 + 快速见结果 + 零运维负担 |
| **为什么 vanilla 零构建？** | MVP 阶段越简单越好，避免过度工程 |
| **为什么三件套统一 GitHub OAuth？** | 账号统一，避免多套凭据，阶段 2 一键关联 GitHub repo |
| **为什么 Postgres？** | JSONB / full-text search / pg_trgm / RLS 全是高级特性，MySQL 没有 |
| **为什么 anime.js + Three.js 不冲突？** | 不同层——Three.js 画 3D canvas，anime.js 动 DOM/CSS，命名空间完全分开 |

## ⚠️ 踩过的坑（备忘）

| 坑 | 原因 | 解法 |
|---|---|---|
| `gh api zipball \| tar` | PowerShell 把 binary 当 string，zip 损坏 | `Start-Process -RedirectStandardOutput` |
| `apply_patch` 编码陷阱 | UTF-8 patch 内容在 PS 里乱码 | 用 OpenClaw 内置 `apply_patch` 工具，不用 shell CLI |
| v2ray 代理端口 | `10808`=SOCKS5，`10809`=HTTP | `Invoke-WebRequest -Proxy 10809` |
| winget install 卡死 | `--proxy` 需要 admin 启用 | `Invoke-WebRequest` 下 msi + `msiexec /i /qn` |
| OpenClaw transcript 雪球 | 读大文件（mp4 / png）触发 transcript 暴涨 | 不 read 二进制，发给聊天窗口用 `image` 工具看 |
