# 01 · 前端技术栈

> **适用**：网页开发项目（MVP / AI 工具 / 创作者平台 / 学习类站点）
> **最后更新**：2026-07-29

---

## 🎯 核心理念

**零构建 · CDN 加载 · vanilla JS**

MVP 阶段越简单越好——不引入 bundler / npm / TS / JSX / React / Vue 等任何增加复杂度的东西。

---

## ✅ 技术选择

### 范式 & 语言

| 维度 | 选择 ✅ | 不选 ❌ |
|---|---|---|
| **HTML** | 原生 HTML5 | JSX / TSX |
| **样式** | CSS Variables + 原生 CSS | Tailwind / Sass / SCSS / CSS-in-JS |
| **脚本** | 原生 JavaScript（ES Modules）| TypeScript |
| **构建** | 零构建 · CDN 加载 | Vite / Webpack / Rollup / esbuild |
| **包管理** | 不在项目里装 npm | package.json 依赖 |

---

> 📦 **3D / 动画 / 图表 / 地图等**按需引入的库 → 看 `08-项目架构选择.md`
> 
> 基础前端栈（vanilla HTML/CSS/ES Modules/CDN）所有项目通用，但 Three.js / anime.js / Chart.js 这些是**项目级架构决策**，按需引入。

### 开发 & 生产服务

### 响应式 & 交互

| 维度 | 选择 ✅ |
|---|---|
| **响应式** | CSS Media Queries + CSS Variables |
| **可达性** | 键盘可达 / ARIA 属性 / focus visible |
| **表单验证** | 原生 HTML5 验证 + JS 增强 |
| **全局状态** | 纯 JS 模块（event bus）+ localStorage |
| **后端接入前 mock** | localStorage（模拟登录 / 收藏 / 点赞）|

---

## ❌ 不引入的技术（反模式）

| 技术 | 原因 |
|---|---|
| React / Vue / Angular | 增加构建复杂度，MVP 不需要 |
| Next.js / Nuxt | 同上 |
| Tailwind CSS | 破坏零构建原则 |
| TypeScript | 强类型带来的维护成本 > 早期收益 |
| npm（项目内）| 依赖版本管理是负担 |
| Vite / Webpack | 额外构建步骤拖慢迭代 |
| Redux / Zustand | localStorage mock + 事件总线足够 |

---

## 📦 CDN 依赖规范

所有外部依赖**必须走 CDN ESM**，格式：

```html
<script type="module" src="https://unpkg.com/[package]@[version]/[path]"></script>
```

禁止：
- `npm install` 在项目目录
- `import xxx from './node_modules/xxx'`
- 任何本地缓存的 vendor 文件

---

## 🔧 开发约定

| 约定 | 规范 |
|---|---|
| **模块化** | 每个功能一个 ES Module（`app.js` / `auth.js` / `store.js` 等）|
| **CSS 路径** | 统一 `styles.css`，按注释分区块 |
| **HTML 路径** | 统一放项目根或 `pages/` 子目录 |
| **字体** | Google Fonts CDN，不下载到本地 |
| **图片** | 统一放 `assets/` 或 `images/`，CDN 引入 |
